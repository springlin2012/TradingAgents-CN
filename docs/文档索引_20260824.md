## 使用说明

- 本索引用于提供全局导航，按“推荐阅读路径、根目录入口、主题目录”组织。
- 各主题目录中的 `README.md`（如存在）是该主题的优先入口；目录内的修复报告、阶段总结和历史方案适合按需检索。
- `archive/`、`bugfix/`、`fixes/`、`summary/` 和旧版本目录以历史记录为主，阅读时应结合当前代码和最新发布说明核对。
- 标记为 **【过时】** 的文档保留用于历史参考，不应作为当前启动、部署或配置依据；当前服务以 FastAPI + Vue 和仓库根目录 `docker-compose.yml` 为准。
- 文档数量会随项目演进变化；新增、迁移或归档文档后，应同步更新本索引的统计和链接。

## 维护约定

1. 新文档应放入 `docs/` 下语义明确的子目录，不在根目录继续堆叠。
2. 新建中文文档按 `文件名称_yyyyMMdd.md` 命名；版本发布、外部同步等已有固定命名体系的文档可沿用其目录规范。
3. 同一主题优先更新现有文档，确需新增时应补充相关目录的 `README.md` 或本索引入口。
4. 修复记录和阶段总结应注明适用版本；过期材料移入 `archive/`，但不要直接删除历史资料。
5. 更新本索引时，至少核对文档总数、一级目录数量、关键入口链接和最新版本说明。
