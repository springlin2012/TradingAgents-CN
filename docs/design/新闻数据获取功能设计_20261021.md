## 1. 目标与边界

系统需要同时支持两类新闻：

| 类型 | 触发条件 | 上游接口（AKShare） | HTTP 入口 |
|---|---|---|---|
| 个股新闻 | 有股票代码 | `ak.stock_news_em(symbol)` | `GET /api/stocks/{code}/news`、`GET /api/news-data/query/{symbol}` |
| 市场新闻 | 无股票代码 | `ak.news_cctv(date)`（Provider 层有封装） | `GET /api/news-data/latest`（只读库）、`POST /api/news-data/sync/start`（不传 `symbol`） |

设计原则：

1. **库优先，空库再拉源**：查询接口先读 MongoDB；个股路径在库空时会实时补数。
2. **个股与市场共用一张表**：都写入 `stock_news`，用 `symbol` / `data_source` 区分，不拆独立 collection。
3. **去重按内容指纹**：`url + title + publish_time` 唯一索引，跨数据源 upsert。
4. **鉴权统一**：除 `/api/news-data/health` 外，新闻 HTTP 接口均需 Bearer Token。

## 2. 总体架构

```
前端
  stocksApi.getNews(symbol)          → GET /api/stocks/{code}/news
  newsApi.getLatestNews(symbol?)     → GET /api/news-data/latest
  newsApi.queryStockNews(symbol)     → GET /api/news-data/query/{symbol}
  newsApi.syncMarketNews()           → POST /api/news-data/sync/start  {symbol: null}

路由层
  app/routers/stocks.py              个股详情页新闻（A股/港股/美股分流）
  app/routers/news_data.py           新闻查询、搜索、统计、同步

服务层
  NewsDataService                    标准化、入库、查询、统计
  NewsDataSyncService                个股多源同步 / 市场新闻同步
  AKShareSyncService.sync_news_data  个股详情页库空时的补数路径

提供器
  AKShareProvider.get_stock_news
      symbol 有值 → ak.stock_news_em
      symbol 为空 → ak.news_cctv
  TushareProvider.get_stock_news
  RealtimeNewsAggregator             实时聚合（市场同步默认源）

存储
  MongoDB.{MONGO_DB}.stock_news
```

主挂载点在 `app/main.py`：

- `news_data.router` → 前缀 `/api/news-data`
- `stocks_router.router` → 前缀 `/api`，路由自身前缀 `/stocks`

## 3. 数据源

### 3.1 AKShare（当前主免费源）

本地版本以 `akshare 1.18.64` 为准。

| 函数 | 用途 | 参数 | 返回列 / 说明 |
|---|---|---|---|
| `ak.stock_news_em(symbol)` | 东方财富个股新闻 | 6 位代码或关键词 | `关键词`、`新闻标题`、`新闻内容`、`发布时间`、`文章来源`、`新闻链接` |
| `ak.news_cctv(date)` | 新闻联播文字稿 | `YYYYMMDD`，20160203 之后 | `date`、`title`、`content` |

实现注意：

- `stock_news_em` 打东方财富搜索 JSONP（`search-api-web.eastmoney.com`），易被反爬。`AKShareProvider` 初始化时会给 `requests.get` 打补丁（补 Header、限速）；Docker 内优先 `curl_cffi` 模拟 Chrome。
- 文档常写「最近约 100 条」，当前源码 `pageSize` 实际为 10。
- 上游结构变化时，常见错误是缺 `cmsArticleWebOld` 字段。
- 旧文档中的 `js_news`、`stock_info_global_em` 在当前 AKShare 版本中已不存在。

项目封装：`tradingagents/dataflows/providers/china/akshare.py`

- 同步：`get_stock_news_sync(symbol=None, limit=10)`
- 异步：`get_stock_news(symbol=None, limit=10)`，返回结构化 list

适配器兜底：`app/services/data_sources/akshare_adapter.py` 的 `get_news()` 调 `stock_news_em`，公告再补 `stock_announcement_em`。

### 3.2 Tushare

个股同步默认数据源之一。需要单独开通新闻权限，积分不足会跳过。来源包括 sina、eastmoney、10jqka、wallstreetcn、cls 等。

### 3.3 实时聚合

`RealtimeNewsAggregator.get_realtime_stock_news(symbol, hours_back, max_news)`。

`symbol=None` 时取市场新闻。当前 **HTTP 市场同步默认只走这一路**，不会自动调 `ak.news_cctv()`。

## 4. HTTP 接口

均返回统一包：`{success, data, message, timestamp}`。

### 4.1 有股票代码（个股）

| 方法 | 路径 | 行为 |
|---|---|---|
| `GET` | `/api/stocks/{code}/news` | 个股详情页主接口。先查库，空则调用 `AKShareSyncService.sync_news_data` 补数。A 股走本路径；美股转 `ForeignStockService`；港股暂返回空 |
| `GET` | `/api/news-data/query/{symbol}` | 库优先；空则实时 `provider.get_stock_news(symbol)` 并入库后再查 |
| `GET` | `/api/news-data/latest?symbol=000001` | 只读库，不实时拉源 |
| `POST` | `/api/news-data/query` | 高级筛选（可带 `symbol` / `symbols` / 时间 / 情绪等），只读库 |
| `POST` | `/api/news-data/sync/single` | 同步执行单股拉取并入库 |
| `POST` | `/api/news-data/sync/start`（body 带 `symbol`） | 后台任务同步该股 |

详情页查询参数：`days`（默认 30）、`limit`（默认 50）、`include_announcements`（默认 true）。A 股当前实现**不按 `days` 过滤**，直接取该股最新 `limit` 条，避免库里只有历史新闻时查空。

### 4.2 无股票代码（市场）

| 方法 | 路径 | 行为 |
|---|---|---|
| `GET` | `/api/news-data/latest`（不传 `symbol`） | 读库中最近 `hours_back` 小时新闻，**不实时拉源**。后端语义是「所有新闻」，不是严格的市场新闻过滤 |
| `POST` | `/api/news-data/query`（不传 `symbol`） | 高级筛选，只读库 |
| `POST` | `/api/news-data/sync/start`（`symbol` 为空 / `null`） | 后台同步市场新闻，写入同一张 `stock_news` |

前端封装见 `frontend/src/api/news.ts`、`frontend/src/api/stocks.ts`。

### 4.3 其他

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/news-data/search` | 标题 / 正文全文搜索 |
| `GET` | `/api/news-data/statistics` | 情绪、重要性、类别、来源分布 |
| `DELETE` | `/api/news-data/cleanup` | 按保留天数清理过期新闻 |
| `GET` | `/api/news-data/health` | 健康检查，无需登录 |

## 5. 存储设计

### 5.1 落库位置

- 数据库：`MONGO_DB`（常见 `tradingagents`）
- 集合：**`stock_news`**
- 写入：`NewsDataService.save_news_data()`，`ReplaceOne(..., upsert=True)`

市场新闻**没有**独立 collection。港股 / 美股预留名 `stock_news_hk`、`stock_news_us` 当前市场同步不写。

旧集合 `news_data` 仅历史缓存，主流程不再写入。

### 5.2 文档 Schema

入库前统一走 `_standardize_news_data()`：

```javascript
{
  // 股票关联（市场新闻为空）
  "symbol": "000001" | null,
  "full_symbol": "000001.SZ" | null,
  "market": "CN",
  "symbols": ["000001"] | [],

  // 正文
  "title": "",
  "content": "",
  "summary": "",
  "url": "",
  "source": "",          // 媒体名
  "author": "",

  // 时间
  "publish_time": ISODate("..."),

  // 分类标签
  "category": "company_announcement" | "policy_news" | "industry_news"
            | "market_news" | "research_report" | "general",
  "sentiment": "positive" | "negative" | "neutral",
  "sentiment_score": Number | null,
  "keywords": ["业绩", "政策", ...],   // 最多 10 个
  "importance": "high" | "medium" | "low",

  // 元数据
  "data_source": "akshare" | "tushare" | "realtime" | "multi_source" | "market_news",
  "created_at": ISODate("..."),
  "updated_at": ISODate("..."),
  "version": 1
}
```

分类、情绪、重要性、关键词目前是基于标题 / 正文的规则匹配，不是独立 NLP 服务。标准化时**不写 `language` 字段**，避免与 MongoDB 文本索引冲突。

### 5.3 个股 vs 市场字段差异

| 字段 | 个股同步 | 市场同步 |
|---|---|---|
| collection | `stock_news` | 同一张 `stock_news` |
| `symbol` | `"000001"` | `null` |
| `full_symbol` | `"000001.SZ"` 等 | `null` |
| `symbols` | `["000001"]` | `[]` |
| `data_source` | `"multi_source"`（多源合并）或 `"akshare"`（实时补数） | `"market_news"`（保存时覆盖） |
| 去重键 | `url + title + publish_time` | 相同 |

区分方式：查市场新闻应过滤 **`symbol` 为空** 或 **`data_source == "market_news"`**，不能换表。

### 5.4 索引

初始化脚本：`scripts/setup/create_news_data_collection.py`。服务首次保存时也会 `_ensure_indexes()`。

| 索引名 | 键 | 用途 |
|---|---|---|
| `url_title_time_unique` | `url + title + publish_time`（unique） | 去重 upsert |
| `symbol_index` | `symbol` | 个股查询 |
| `symbols_index` | `symbols` | 多标的新闻 |
| `publish_time_desc` | `publish_time` 降序 | 时间范围 / 最新 |
| `symbol_time_index` | `symbol + publish_time` | 个股按时间 |
| `data_source_index` | `data_source` | 按源筛选 |
| `category_index` / `sentiment_index` / `importance_index` | 对应字段 | 统计与过滤 |
| `updated_at_index` | `updated_at` | 维护 |

脚本还会建文本索引 `title + content + summary`。服务侧 `_ensure_indexes()` 未重复创建文本索引。

## 6. 同步流程

### 6.1 个股新闻

```
sync_stock_news(symbol)
  ├─ TushareProvider.get_stock_news(symbol)     data_source=tushare
  ├─ AKShareProvider.get_stock_news(symbol)     → stock_news_em
  └─ RealtimeNewsAggregator(symbol)
        ↓ 标题+URL 去重
  save_news_data(..., data_source="multi_source", market="CN")
        ↓
  stock_news  upsert
```

默认 `data_sources = ["tushare", "akshare", "realtime"]`。

个股详情页库空时的补数走 `AKShareSyncService.sync_news_data(symbols=[code])`，最终仍写入 `stock_news`。

### 6.2 市场新闻

```
POST /api/news-data/sync/start  { symbol: null }
  → NewsDataSyncService.sync_market_news()
      默认 data_sources = ["realtime"]
      RealtimeNewsAggregator.get_realtime_stock_news(None, ...)
      _standardize_realtime_news(..., symbol=None)
        ↓
      save_news_data(..., data_source="market_news", market="CN")
        ↓
      stock_news  （symbol=null）
```

`AKShareProvider.get_stock_news(symbol=None)` → `ak.news_cctv()` 已实现，但 **本 HTTP 同步路径未接入**。

## 7. 查询策略

| 场景 | 读库条件 | 是否实时补数 |
|---|---|---|
| 个股详情 `GET /api/stocks/{code}/news` | `symbol = code`，不限时间，按 `publish_time` 倒序 `limit` 条 | 是（AKShare 同步） |
| 个股 `GET /api/news-data/query/{symbol}` | `symbol` + `hours_back` | 是（直接 `get_stock_news`） |
| 最新 `GET /api/news-data/latest` | 可选 `symbol` + `hours_back` | 否 |
| 市场同步后查看 | 同上，不传 `symbol` 时返回窗口内**全部**新闻 | 需先 `sync/start` |

`GET /api/news-data/latest` 不传 `symbol` 时**不会**过滤 `symbol: null` 或 `data_source: market_news`，可能混入个股新闻。前端注释写成「市场新闻」，与后端「所有新闻」不一致。

## 8. 已知缺口

1. **没有「不传代码就实时返回 CCTV 市场新闻」的 GET**。市场侧只有后台同步 + 读库。
2. **市场同步未接 `ak.news_cctv()`**。Provider 有封装，`sync_market_news()` 默认只用 realtime。
3. **市场 / 个股共用一张表**，latest 接口未按市场新闻语义过滤。
4. **港股新闻未实现**，`GET /api/stocks/{hk}/news` 返回空列表。
5. **AKShare 个股新闻条数受上游 `pageSize` 限制**，且依赖反爬补丁；缺 `cmsArticleWebOld` 时返回空而不抛崩。
6. 情绪 / 分类 / 重要性为关键词规则，精度有限。

后续若要补齐市场新闻实时查询，建议：

- `GET /api/news-data/latest` 增加 `scope=market|stock|all`
- 市场同步 `data_sources` 默认纳入 `akshare`，调用 `get_stock_news(symbol=None)`
- 查询市场新闻时显式过滤 `symbol: null` 或 `data_source: "market_news"`
