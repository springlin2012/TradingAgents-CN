# A股股票名称模糊匹配与自动填充开发计划

> 保存日期：2026-10-10
> 方案：A股自动补全 + 完善已有 A股搜索接口
> 状态：已按计划实施；本文保存确认的开发范围和验收要求。

## 一、方案摘要

在“添加自选股”弹窗中，仅对 A股股票名称启用自动补全。用户输入名称后调用已有 `/api/stock-data/search` 接口，展示候选股票名称和代码；选中后自动填充 `stock_name` 与 `stock_code`。港股、美股及原有代码失焦查名称逻辑保持兼容。

## 二、后端实现

修改文件：

- `app/services/stock_data_service.py`
- `app/routers/stock_data.py`

新增 `StockDataService.search_stock_candidates(keyword, limit=10)`：

1. 查询本地 `stock_basic_info` 集合，不调用外部行情数据源。
2. 对股票名称进行字面子串匹配，使用 `re.escape` 防止特殊字符扩大正则范围。
3. 同时兼容 `symbol`、`code` 字段，代码统一为六位字符串。
4. 按 `tushare → multi_source → akshare → baostock → 其他来源` 选择同一股票的最佳匹配记录。
5. 按股票代码去重。
6. 排序优先级为名称完全匹配、名称前缀匹配、名称包含匹配，同级按代码升序。
7. 最多返回10条候选，返回字段固定为 `symbol`、`name`、`source`。

扩展现有接口：

```http
GET /api/stock-data/search?keyword=海&limit=10&mode=autocomplete
```

- `mode=default`：保持现有接口行为，省略参数时采用此模式。
- `mode=autocomplete`：调用新的候选搜索逻辑。
- 自动模式去除关键词首尾空白，空白关键词或超过50字符返回参数错误。
- 接口 `limit` 接受1～50，自动模式实际最多返回10条。
- 保留现有登录鉴权和响应包装格式，`data` 为候选数组。

## 三、前端实现

新增文件：

- `frontend/src/api/stockData.ts`
- `frontend/src/composables/useStockNameAutocomplete.ts`

修改文件：

- `frontend/src/views/Favorites/index.vue`
- 必要时修改 `frontend/src/api/request.ts`

交互与状态要求：

1. A股名称字段使用 `el-autocomplete`；港股、美股继续使用普通名称输入框。
2. 设置300毫秒防抖，最多显示10条候选。
3. 候选显示“股票名称 + 六位代码”，支持鼠标点击、上下键、回车和 Esc。
4. 选中候选后同时写入 `stock_name` 和 `stock_code`，不重复触发代码查名称请求。
5. 选中后再次修改名称时清除自动填入的旧代码。
6. 手动修改代码时清除旧的自动选择状态及相应自动名称。
7. 市场切换、关闭弹窗、重新打开弹窗时清除候选和请求状态。
8. 使用请求版本号、关键词、市场和弹窗会话号校验响应，防止旧请求覆盖新输入；代码查名也校验编辑版本和会话。
9. 搜索失败仅显示字段附近提示，不重复弹出全局错误消息。
10. 添加成功、重复添加、标签和备注沿用原有流程。

如现有请求拦截器未正确尊重 `skipErrorHandler`，补充搜索相关 HTTP、网络和超时错误分支的静默处理，401鉴权处理保持不变。搜索请求关闭自动重试。

## 五、测试与验收

### 后端测试

文件：`tests/test_stock_name_candidates.py`。

- 名称包含匹配。
- 完全匹配和前缀匹配排序。
- 多数据源同代码去重。
- 首选数据源缺失时回退其他来源。
- `symbol/code` 字段兼容。
- 代码补齐为六位字符串。
- 特殊字符按字面匹配。
- 空关键词和结果数量限制。
- 默认搜索模式行为不变。

在项目根目录执行：

```powershell
python -m pytest -c tests/pytest.ini tests/test_stock_name_candidates.py -q
```

真实聚合测试使用随机隔离 MongoDB 测试库并在结束时清理。默认仅自动连接本机 MongoDB；显式指定测试连接可设置 `TEST_STOCK_CANDIDATES_MONGO_URI`。未提供可用测试库时，聚合测试会跳过。

### 前端测试与检查

前端状态和请求测试使用 Node.js 内置测试工具，直接验证 Vue/TypeScript 逻辑，不引入新测试框架。在项目根目录执行：

```powershell
node --test tests/frontend/test_stock_name_autocomplete.cjs tests/frontend/test_stock_search_request.cjs
```

在前端目录执行：

```powershell
cd frontend
npm run type-check
npm run lint -- --no-fix --ignore-path ../.gitignore
npm run build
```

lint 使用根目录忽略文件，避开原脚本引用不存在的 `frontend/.gitignore`；`--no-fix` 避免修改无关文件。当前依赖环境缺少 `@rushstack/eslint-patch` 时需补齐，原实施未修改依赖清单和锁文件。

- 本次只实现 A股名称模糊搜索。
