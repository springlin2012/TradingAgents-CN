# A 股指数查询后端实现计划

> 日期：2026-10-21  
> 依据：[指数查询系统设计_20261020.md](../features/minniprogram/指数查询系统设计_20261020.md)  
> 契约：[指数查询接口设计_20261019.md](../features/minniprogram/指数查询接口设计_20261019.md)  
> 范围：后端 `/api/indexes`；前端大盘条延期  
> 2026-10-21 修订：不提供 K 线；指数行情不从 Tushare 取数

## 1. 口径（已拍板）

- 深证指数 = 深证成指 `399001.SZ`（不是综指 `399106.SZ`）
- 指数行情：Mongo → AKShare `stock_zh_index_spot_em`（spot 缺失时 adapter 内用日线最新一行补行情）
- **不从 Tushare / BaoStock 取指数数据**
- **不提供** `/api/indexes/{code}/kline`，不建 `index_daily_quotes`，不注册日 K 调度
- 独立路由 `/api/indexes` + 独立集合，不碰个股 `000001` / `market_quotes`
- 裸 `000001` 拒绝；`399300.SZ` 归一 `000300.SH`；北证禁止 `sh/sz` 前缀

## 2. 实现顺序

1. `app/services/index_catalog.py` + `tests/unit/test_index_catalog.py`
2. `app/models/index_models.py`
3. AKShare `get_index_quotes` + manager 仅 AKShare fallback + `tests/unit/test_index_adapters.py`
4. Mongo `index_quotes` 索引 + `IndexDataService`（无 K 线）
5. `app/routers/indexes.py` 挂载目录/批量/单只行情 + `tests/unit/test_index_api.py`
6. `IndexQuotesIngestionService` 快照入库 + 配置 + 调度 + `tests/unit/test_index_ingestion.py`
7. 回归 `tests/unit/test_stocks_kline_news_api.py`

## 3. 文件清单

新建：catalog / models / data_service / ingestion / indexes 路由 / 四份单测。  
修改：`base.py`（可选 `get_index_quotes`，不加 abstract）、`akshare_adapter.py`、`manager.py`、`database.py`、`config.py`、`main.py`。  
不改：`tushare_adapter.py` 个股方法、BaoStock 个股 `get_kline`。
