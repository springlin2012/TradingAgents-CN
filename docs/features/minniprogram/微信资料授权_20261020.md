# 微信资料授权设计

> 日期：2026-10-20  
> 范围：用户主动授权头像、昵称后，用于「我的」页展示，不改内部登录账号。

## 一、结论

微信登录只能拿到 openid，**不能静默读取昵称和头像**。官方要求用：

- 头像：`<button open-type="chooseAvatar">`
- 昵称：`<input type="nickname">`

内部 `username`（`wx_{openid}`）继续给 JWT 用。展示走独立字段 `nickname` / `avatar`。

## 二、流程

```
微信登录成功
  → 尚无 nickname
  → 进入 pages/loginProfile/loginProfile
  → 用户点头像、点昵称输入框授权
  → POST /api/auth/avatar 上传头像
  → POST /api/auth/profile 保存昵称
  → 「我的」展示 nickname，不再展示 wx_...
```

可点「暂不授权」跳过，之后在「我的 → 完善微信资料」再填。

## 三、接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/profile` | `{ nickname, avatar? }`，需登录 |
| POST | `/api/auth/avatar` | `multipart/form-data` 字段 `file` |
| GET | `/api/auth/avatars/{filename}` | 读已上传头像 |
| GET | `/api/auth/me` | 返回 `nickname`、`avatar`、`name`（优先昵称） |

`username` 不因授权而改变。

## 四、关键文件

小程序：`pages/loginProfile/`、`api/auth.js`、`utils/auth.js`、`pages/my/index.*`  
后端：`app/models/user.py`、`app/routers/auth_db.py`、`app/services/user_service.py`

## 五、验证

1. 重启 TradingAgents-CN。  
2. 微信开发者工具真机或模拟器（H5 预览拿不到真实授权组件）。  
3. 微信登录后进入完善资料页，点头像、点昵称，保存后「我的」显示微信昵称。  
4. 跳过后再从「完善微信资料」进入，效果相同。
