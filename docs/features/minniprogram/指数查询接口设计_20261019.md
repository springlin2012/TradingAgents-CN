# A 股核心指数查询接口设计

> 状态：设计完成，待实现  
> 日期：2026-10-19  
> 范围：上证指数、深证成指、创业板指、沪深300、科创50、北证50

## 1. 背景与结论

当前系统已有个股行情链路：

- `GET /api/stocks/{code}/quote`：读 `market_quotes`，6 位代码主键
- `GET /api/stocks/{code}/kline`：先读 `stock_daily_quotes`，再走 `DataSourceManager.get_kline_with_fallback`
- 全市场快照入库：`QuotesIngestionService` → `market_quotes`

这条链路**不能直接复用给指数**，核心原因：

1. **代码歧义**：上证指数 `000001.SH` 与平安银行 `000001.SZ` 同号不同市场。现有 `_detect_market_and_code("000001")` 会把它当 A 股个股。
2. **集合主键冲突**：`market_quotes` / `stock_daily_quotes` 以 6 位 `code` 为键，写入 `000001` 会覆盖或污染个股数据。
3. **数据源接口不同**：Tushare 个股走 `rt_k` / `pro_bar`，指数应走 `index_daily` / `index_dailybasic`；AKShare 个股走 `stock_zh_a_hist`，指数应走 `stock_zh_index_*`。
4. **北证所代码段**：北证50 是 `899050.BJ`，不能按沪/深前缀推断。

因此 v1 采用**独立指数目录 + 独立路由 + 独立 Mongo 集合**，只覆盖用户指定的 6 只宽基指数，不开放任意指数代码。

## 2. 设计目标

1. 一次请求可查 6 只指数的最新点位，供首页大盘条使用。
2. 单只指数支持最新行情和日/周/月 K 线。
3. 对外接受中文名、别名、6 位代码、`000001.SH`、`sh000001` 等多种输入，对内一律归一成 `full_symbol`。
4. 数据源按现有优先级降级：Mongo 缓存 → Tushare → AKShare → BaoStock。
5. 字段口径与个股接口尽量对齐，但显式标记 `asset_type=index`，并强制带市场后缀。
6. 不把指数数据写入 `market_quotes` / `stock_daily_quotes`。

非目标（v1 不做）：

- 任意中证/国证指数开放查询
- 成分股、权重、调样历史
- 分钟级 K 线
- 指数估值序列的完整财务口径（PE/PB 仅作为行情可选字段）

## 3. 指数目录（唯一真相源）

实现时落在 `app/services/index_catalog.py` 的静态常量，不从数据源动态发现。未命中目录一律 `404`，避免把个股当指数。

| 内部 ID | 官方名称 | full_symbol | 交易所 | 编制机构 | 别名 |
| --- | --- | --- | --- | --- | --- |
| `sse_composite` | 上证综合指数 | `000001.SH` | SSE | 上交所 | 上证指数、上证综指、上证、sse、sh000001、000001.SH |
| `szse_component` | 深证成份指数 | `399001.SZ` | SZSE | 深交所 | 深证指数、深证成指、深成指、szse、sz399001、399001.SZ |
| `chinext` | 创业板指数 | `399006.SZ` | SZSE | 深交所 | 创业板指、创业板、sz399006、399006.SZ |
| `csi300` | 沪深300指数 | `000300.SH` | CSI（跨沪深） | 中证指数 | 沪深300、hs300、csi300、sh000300、000300.SH、399300.SZ |
| `star50` | 上证科创板50成份指数 | `000688.SH` | SSE | 上交所 | 科创50、kcb50、star50、sh000688、000688.SH |
| `bse50` | 北证50成份指数 | `899050.BJ` | BSE | 北交所 | 北证50、bj50、bj899050、899050.BJ |

硬规则：

1. **禁止裸 6 位 `000001` 作为指数代码**。该输入必须拒绝或要求带市场后缀，避免与平安银行混淆。`399001` / `399006` / `000300` / `000688` / `899050` 因与个股号段无冲突，允许 6 位简写，但仍建议客户端传 `full_symbol`。
2. **沪深300 双代码归一**：`399300.SZ` 只作为别名，响应里永远返回 `000300.SH`。
3. **北证50 必须带 `.BJ`**，禁止写成 `sh899050` / `sz899050`。
4. ExchangeType 现有字面量是 `SZSE | SSE | SEHK | NYSE | NASDAQ`，实现时扩展 `BSE` 和指数编制方 `CSI`（仅用于指数元数据，不改个股模型）。

参考代码与点位校验时点：2026-10-19 收盘（来源：行情检索 / NeoData）。该数字只用于核对代码有效，接口实现不得硬编码点位。

## 4. 接口一览

统一前缀：`/api/indexes`  
鉴权：与个股接口一致，`Depends(get_current_user)`  
响应包：沿用 `app.core.response.ok`，结构 `{success, data, message, timestamp}`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/indexes` | 返回 6 只指数目录（不含行情） |
| GET | `/api/indexes/quotes` | 批量最新行情，默认 6 只 |
| GET | `/api/indexes/{code}/quote` | 单只最新行情 |
| GET | `/api/indexes/{code}/kline` | 单只 K 线 |

不提供 POST 查询体。批量查询用 query 参数即可，6 只指数无需分页。

### 4.1 目录 `GET /api/indexes`

无业务参数。

```json
{
  "success": true,
  "message": "ok",
  "timestamp": "2026-10-19T16:00:00+08:00",
  "data": {
    "count": 6,
    "items": [
      {
        "id": "sse_composite",
        "name": "上证综合指数",
        "short_name": "上证指数",
        "full_symbol": "000001.SH",
        "symbol": "000001",
        "exchange": "SSE",
        "publisher": "上海证券交易所",
        "sample_count": null,
        "weighting": "total_shares",
        "base_date": "1990-12-19",
        "aliases": ["上证指数", "上证综指", "sse", "sh000001"]

```

`sample_count` 可为 `null`：上证综指是全样本，数量随上市家数变化，不在接口里写死。

### 4.2 批量行情 `GET /api/indexes/quotes`

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| codes | string | 空=全部 6 只 | 逗号分隔，支持别名。例：`sse,399006.SZ,北证50` |
| force_refresh | bool | false | true 时跳过 Mongo，直连外部源 |

单只失败不影响其他标的：该元素 `available=false`，并带 `error`。整体仍 `success=true`。6 只全失败才返回 502。

```json
{

  "data": {
    "trade_session": "closed",
    "timezone": "Asia/Shanghai",
    "as_of": "2026-10-19T15:00:00+08:00",
    "items": [
      {
        "id": "csi300",
        "name": "沪深300指数",
        "full_symbol": "000300.SH",
        "symbol": "000300",
        "asset_type": "index",
        "exchange": "CSI",
        "price": 4174.53,
        "open": 4148.35,
        "high": 4192.02,
        "low": 4143.66,
        "prev_close": 4170.61,
        "change": 3.92,
        "change_percent": 0.09,
        "amplitude": 1.16,
        "volume": 151084956,
        "amount": 36344775000,
        "turnover_rate": 0.45,
        "pe": null,
        "pb": null,
        "trade_date": "2026-10-19",
        "trade_session": "closed",
        "data_source": "tushare",
        "updated_at": "2026-10-19T15:00:12+08:00",
        "available": true
      }
    ]
  }

```

字段对齐说明：

- `price` 对应个股接口的 `price`/`close`，指数场景表示点位。
- `change_percent` 对应个股 `change_percent`/`pct_chg`。
- `volume` 统一为**手**；`amount` 统一为**元**。外部源单位必须在适配层换算，禁止把 Tushare「千元」原样返回。
- `pe` / `pb` 可选。Tushare `index_dailybasic` 有则填，AKShare 无则 `null`，不要编造。

### 4.3 单只行情 `GET /api/indexes/{code}/quote`

路径 `code` 解析顺序：

1. `full_symbol`（`000001.SH`）
2. 终端简写（`sh000001` / `sz399001` / `bj899050`）
3. 目录 `id` 或中文别名
4. 无歧义的 6 位代码（不含 `000001`）

`000001`、未知代码、把个股代码当指数：HTTP 400，message 明确写出「上证指数请使用 000001.SH」。

未找到行情：HTTP 404。数据源超时：HTTP 504。

### 4.4 K 线 `GET /api/indexes/{code}/kline`

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| period | `day/week/month` | `day` | v1 不支持分钟线 |
| limit | int | 120 | 1–1000 |
| start_date | `YYYY-MM-DD` | 空 | 与 end_date 同时出现时优先于 limit |
| end_date | `YYYY-MM-DD` | 空 | 默认今天（北京时间） |
| force_refresh | bool | false | 跳过 Mongo |

指数 K 线**无复权参数**。`adj` 即使传入也忽略，响应里固定 `adj: "none"`，避免前端复用个股 K 线组件时误传 `qfq`。

```json
{
  "success": true,
  "data": {
    "id": "star50",
    "name": "上证科创板50成份指数",
    "full_symbol": "000688.SH",
    "period": "day",
    "limit": 120,
    "adj": "none",
    "source": "mongodb",
    "count": 120,
    "items": [
      {
        "time": "2026-10-19",
        "open": 1347.09,
        "high": 1356.42,
        "low": 1323.67,
        "close": 1329.19,
        "volume": 7745895,
        "amount": 6870233000,
        "change_percent": -2.17
      }
    ]
  }
}
```

K 线按时间正序。Mongo 无数据时降级外部源，并在 `source` 中返回实际来源。

## 5. 代码解析与交易时段

### 5.1 解析器

`resolve_index_code(raw: str) -> IndexSpec`

1. `strip` + 中英文标点归一。
2. 目录别名表精确匹配（大小写不敏感）。
3. 正则：
   - `^(sh|sz|bj)(\d{6})$`
   - `^(\d{6})\.(SH|SZ|BJ)$`
4. 仅当 6 位代码在目录中**唯一**时才接受裸代码。
5. `000001` 单独拒绝。
6. `399300` / `399300.SZ` 映射到 `000300.SH`。

### 5.2 交易时段

时区固定 `Asia/Shanghai`，与 `QuotesIngestionService` 一致。

| 状态 | 条件 | 行情含义 |
| --- | --- | --- |
| `pre_market` | 交易日 00:00–09:30 | 返回上一交易日收盘 |
| `trading` | 09:30–11:30 或 13:00–15:00 | 盘中最新 |
| `lunch` | 11:30–13:00 | 返回上午最新 |
| `closed` | 交易日 15:00 后 | 当日收盘；未入库则上一交易日 |
| `holiday` | 非交易日 | 最近交易日收盘 |

`trade_date` 永远是**数据所属交易日**，不是服务器日历日。休市时不得把昨日收盘表述为「今日实时」。

## 6. 数据源与降级

```
请求
  → IndexCatalog.resolve
  → Mongo（index_quotes / index_daily_quotes）
      命中且未 force_refresh → 返回，source=mongodb
  → DataSourceManager.get_index_*_with_fallback
      Tushare → AKShare → BaoStock
  → 写入 Mongo 后返回
```

### 6.1 适配器职责（新增，不复用个股方法）

在 `DataSourceAdapter` 增加可选方法，默认返回 `None`，避免 BaoStock 为抽象方法被迫空实现报错。Manager 增加：

- `get_index_quotes_with_fallback(full_symbols: list[str])`
- `get_index_kline_with_fallback(full_symbol, period, limit, start, end)`

| 数据源 | 最新行情 | 日/周/月 K 线 | 备注 |
| --- | --- | --- | --- |
| Tushare | `index_daily` 最新一行；有权限再补 `index_dailybasic` | `index_daily` / `index_weekly` / `index_monthly` | `ts_code=000001.SH`。北证50 需确认账号是否覆盖 `899050.BJ` |
| AKShare | `stock_zh_index_spot_em()` 按代码过滤 | `stock_zh_index_daily_em(symbol="sh000001")` 等 | 代码必须带 `sh/sz/bj` 前缀。北证50 若 spot 无数据，改走东财指数日线最新一行 |
| BaoStock | 不提供可靠实时，返回 `None` | `query_history_k_data_plus("sh.000001")` | 北证50 大概率不可用，允许该标的单独失败 |

禁止事项：

- 禁止对指数调用 `stock_zh_a_hist` / `pro_bar` / `rt_k`。
- 禁止把 `000001` 送给个股实时快照接口。
- 禁止在回答或测试夹具里写死点位作为业务数据。

### 6.2 单位换算

实现时必须在适配器内完成，路由层只收标准单位。

| 来源 | 原始成交量 | 原始成交额 | 转换后 |
| --- | --- | --- | --- |
| Tushare `index_daily` | `vol`（手） | `amount`（千元） | volume=手，amount×1000=元 |
| AKShare 东财指数 | 以接口文档为准，常见为手 / 元 | 以接口文档为准 | 写入前用实测样例断言数量级（上证成交额应在 10^11 元量级） |
| BaoStock | 手 | 元 | 按文档核对 |

数量级校验失败时该字段置 `null` 并打 warning，不要把错误单位的数字返回给前端。

## 7. 同步任务

新增 `IndexQuotesIngestionService`，不要并进 `QuotesIngestionService`。

- 交易时段：默认 60 秒拉一次 6 只快照（量很小，可比全市场个股更勤）。
- 收盘后：15:05 再拉一次日 K，写入 `index_daily_quotes`。
- 非交易日：跳过，保留上次收盘。
- 单只失败记 `index_ingestion_status`，不阻断其余 5 只。
- 调度挂在 `app/main.py` 现有 APScheduler 上，配置项：
  - `INDEX_QUOTES_INGEST_INTERVAL_SECONDS`（默认 60）
  - `INDEX_QUOTES_INGEST_ENABLED`（默认 true）

查询接口不依赖调度已跑过：Mongo 无数据时实时降级外部源，保证冷启动可用。

## 9. 错误码

| HTTP | 场景 |
| --- | --- |
| 400 | 代码无法解析、裸 `000001`、period 非法、日期格式错误、start>end |
| 401 | 未登录 |
| 404 | 已解析但无此指数，或该指数无任何行情 |
| 502 | 6 只全部外部源失败 |
| 504 | 单源超时（建议 `asyncio.wait_for(..., 10)`，与个股 K 线一致） |

业务失败体仍用 `{success:false, message, timestamp}`，`message` 用中文，写清代码和建议写法。

## 10. 测试要点

1. 别名：`上证指数`、`sse`、`sh000001`、`000001.SH` 都解析到同一 `id`。
2. 歧义：`000001` → 400；`000001.SZ` → 400（这是平安银行，不在指数目录）。
3. 沪深300：`399300.SZ` 响应 `full_symbol=000300.SH`。
4. 北证50：`899050.BJ` 成功；`sh899050` → 400。
5. 批量部分失败：科创50 源失败时其余 5 只仍返回，该项 `available=false`。
6. 单位：Tushare amount 千元必须乘 1000。
7. 冷启动：Mongo 空时能从 AKShare 拉到日 K。
8. 不污染个股：调用指数接口后 `market_quotes` 中 `code=000001` 仍是平安银行（若原本有）。

## 11. 实现顺序

1. 目录与解析器 + 单测。
2. Tushare / AKShare 指数适配 + 单位断言。
3. Service + Mongo 集合索引。
4. Router 四个端点 + 挂载。
5. 入库调度。
6. 前端 `indexes.ts` 与大盘条（可另开任务）。

## 12. 风险

1. Tushare 免费积分可能没有 `index_dailybasic` 或北证指数权限 → 字段允许 `null`，北证50 走 AKShare。
2. AKShare 东财接口限流 → 沿用现有 adapter 的异常捕获，Manager 降级。
3. 成交额单位各源不一致 → 必须做数量级断言，这是本接口最容易静默出错的点。
4. 前端若复用 `GET /api/stocks/000001/quote` 展示上证指数，结果会是平安银行。大盘条必须改走 `/api/indexes`。
