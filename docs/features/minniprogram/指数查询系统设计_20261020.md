# A 股指数查询系统设计

> 状态：已按实现调整（无 K 线，指数行情不走 Tushare）  
> 日期：2026-10-21  
> 分支：`feature_quotes_info`  
> 接口契约：[指数查询接口设计_20261019.md](指数查询接口设计_20261019.md)  
> 本文档是实现向系统设计，不重复接口 JSON 样例。

## 1. 背景与边界

现有个股链路不能承载指数：

| 冲突点 | 现状 | 后果 |
| --- | --- | --- |
| 路由 | `GET /api/stocks/000001/quote` | 命中平安银行，不是上证指数 |
| Mongo | `market_quotes.code` 全局 unique | 指数 `000001` 会覆盖个股 |
| Tushare | `_normalize_ts_code("000001")` → `000001.SZ` | 永远不会变成 `000001.SH` |
| AKShare | `stock_zh_a_hist` / `stock_zh_a_spot*` | 个股接口，不是指数 |
| 筛选视图 | `$lookup market_quotes` 用 `code` | 指数写入会污染个股行情 |

v1 方案：独立目录、独立路由、独立集合、独立适配方法。

### 覆盖范围

只开放 6 只宽基。用户说法「深证指数」已确认为**深证成指**，不是综指 `399106.SZ`。

| 内部 ID | 名称 | full_symbol |
| --- | --- | --- |
| `sse_composite` | 上证综指 | `000001.SH` |
| `szse_component` | 深证成指 | `399001.SZ` |
| `chinext` | 创业板指 | `399006.SZ` |
| `csi300` | 沪深300 | `000300.SH` |
| `star50` | 科创50 | `000688.SH` |
| `bse50` | 北证50 | `899050.BJ` |

### v1 不做

- 任意中证 / 国证指数开放查询
- 成分股、权重、调样历史
- 指数 K 线（含日/周/月/分钟）、复权
- 从 Tushare / BaoStock 取指数数据
- 改个股 `ExchangeType`
- 前端 `indexes.ts`、大盘条、小程序（延期）
- 把指数并进 `QuotesIngestionService` 的 `rt_k` 轮换

## 2. 架构总览

```
GET /api/indexes*
  → app/routers/indexes.py
       Depends(auth_db.get_current_user)
       ok() 响应包
  → IndexCatalog.resolve_index_code
  → IndexDataService
       Mongo index_quotes
       miss 或 force_refresh
         → DataSourceManager.get_index_quotes_with_fallback
              仅 AKShare spot（缺失时 adapter 内用日线最新一行补行情）
         → upsert 回独立集合后返回

调度（与查询解耦）：
  IndexQuotesIngestionService
    交易时段 60s 快照 → index_quotes
查询不依赖调度已跑过；冷启动走外部源。不注册日 K 任务。
```

模块落点：

| 文件 | 职责 |
| --- | --- |
| `app/services/index_catalog.py` | 6 只常量、别名、拒绝规则、`full_symbol` 转换 |
| `app/models/index_models.py` | `IndexExchange`、响应模型；不改 `stock_models` |
| `app/services/index_data_service.py` | 行情编排、时段、缓存读写（无 K 线） |
| `app/services/index_quotes_ingestion_service.py` | 定时入库快照 |
| `app/routers/indexes.py` | `APIRouter(prefix="/indexes")` |
| `app/services/data_sources/base.py` | 可选 `get_index_quotes`，默认 `None`，不加 abstract |
| `app/services/data_sources/akshare_adapter.py` | 指数现货实现 |
| `app/services/data_sources/manager.py` | `get_index_quotes_with_fallback`，仅 AKShare，键用 `full_symbol` |
| `app/core/database.py` | `index_quotes` / `index_ingestion_status` 索引 |
| `app/core/config.py` | `INDEX_QUOTES_INGEST_*` |
| `app/main.py` | `include_router` + 快照 scheduler job |

不必改 `app/routers/__init__.py`。挂载方式与 stocks 一致：

```python
from app.routers import indexes as indexes_router
app.include_router(indexes_router.router, prefix="/api", tags=["indexes"])
```

## 3. 代码解析规则

`resolve_index_code(raw: str) -> IndexSpec`，失败抛 `IndexResolveError`，路由映射为 HTTP 400。

处理顺序：

1. `strip`；全角点 / `．` → `.`；去空白；大小写不敏感。
2. 别名表精确匹配（`id`、官方名、短名、aliases）。
3. 正则 `^(sh|sz|bj)(\d{6})$` 或 `^(\d{6})\.(SH|SZ|BJ)$`。
4. 裸 6 位：仅当目录中唯一且允许简写。

硬拒绝：

- 裸 `000001` → 「上证指数请使用 000001.SH」
- `000001.SZ` / `sz000001` → 平安银行，不在目录
- `sh899050` / `sz899050` → 北证必须 `.BJ` 或 `bj899050`
- 未知代码

允许裸 6 位：`399001` / `399006` / `000300` / `000688` / `899050`。  
沪深300：`399300` / `399300.SZ` / `sz399300` 一律归一成 `000300.SH`。

数据源代码由 catalog 生成，**禁止**走 Tushare `_normalize_ts_code`：

| 用途 | 格式 |
| --- | --- |
| 对内主键 | `000001.SH` |
| AKShare | `sh000001` / `sz399001` / `bj899050` |

`IndexExchange = Literal["SSE", "SZSE", "BSE", "CSI"]` 只用于指数元数据。沪深300 的 `exchange` 为 `CSI`。不要把 `CSI` 加进个股 `ExchangeType`。

## 4. 数据源映射与单位

相对接口设计 §6 的修正（2026-10-21 再修订）：**指数行情不走 Tushare**，也不提供 K 线。

### 4.1 quote 降级

1. Mongo `index_quotes`（未 `force_refresh`）
2. AKShare `stock_zh_index_spot_em()`，按 `sh000001` 等过滤
3. spot 缺失时，AKShare adapter 内用 `stock_zh_index_daily_em` 最新一行补行情

Tushare / BaoStock 不参与指数行情。

北证50 若 spot 无数据，同样走东财指数日线最新一行。

### 4.2 kline

不实现。不建 `index_daily_quotes`，不注册日 K 调度，路由 `/kline` 不存在。

### 4.3 禁止调用

- Tushare `index_daily` / `index_dailybasic` / `pro_bar` / `rt_k`
- `stock_zh_a_hist` / `stock_zh_a_spot*`
- 把裸 `000001` 送给个股实时快照
- 在实现或测试夹具里把点位当业务真相硬编码

### 4.4 单位

适配器内换算，路由只收标准单位：`volume`=手，`amount`=元。

| 来源 | volume | amount |
| --- | --- | --- |
| AKShare 东财指数 | 以接口实测为准 | 写入前做数量级断言 |

上证成交额换算后应在 `1e11` 元量级。失败则该字段 `null` + warning，不要把错误单位返回。PE/PB 无权限就 `null`，不编造。

基类新方法必须是可选默认 `None`，**不加 `@abstractmethod`**，否则 BaoStock 现有抽象实现会被破坏。Manager 的 fallback 键必须是 `full_symbol`，绝不是 6 位 `code`。

## 5. Mongo 集合与索引

两个新集合，**永不写入** `market_quotes` / `stock_daily_quotes`。不建 `index_daily_quotes`。

### `index_quotes`

1 只指数 1 行。唯一索引：`full_symbol`。另建 `updated_at` 降序。主键语义与个股 `code` 隔离。

字段对齐接口设计：`id, name, full_symbol, symbol, price, OHLC, prev_close, change, change_percent, amplitude, volume, amount, turnover_rate, pe, pb, trade_date, data_source, updated_at, data_version`。

### `index_ingestion_status`

唯一索引：`job`。取值 `index_quotes_ingestion`。字段对齐现有 `quotes_ingestion_status`（last_sync / success / source / error）。

权威建索引位置：`app/core/database.py` 的 `create_database_indexes`。`IndexQuotesIngestionService.ensure_indexes()` 启动时再 ensure 一次，与个股 `QuotesIngestionService` 相同模式。

## 6. 查询编排

`IndexDataService`：

- `get_catalog()`
- `get_quotes(raw_codes, force_refresh)`
- `get_quote(raw_code, force_refresh)`

路径：

```
resolve → Mongo（非 force_refresh）
  命中 → source=mongodb
  未命中 → asyncio.wait_for(to_thread(manager.get_index_*), 10)
           超时 HTTP 504
         → upsert 独立集合 → 返回
```

规则：

- 批量：单只失败 `available=false` + `error`，其余照常；6 只全失败且无缓存 → 502。
- 未解析 → 400；已解析但无行情 → 单只 404。
- `trade_date` 是数据所属交易日，不是服务器日历日。休市不得把昨日收盘表述为「今日实时」。
- 路由注册：`/quotes` 必须写在 `/{code}` 之前。

## 7. 交易时段

时区：`settings.TIMEZONE`（默认 `Asia/Shanghai`）。

v1 **不做交易所日历**，与现有 `QuotesIngestionService` 一致：周一到周五 + 时点。周末标 `holiday`。法定节假日若落在工作日，可能被标成 `closed` 而非 `holiday`，实现时文档与注释需写明。

| 状态 | 条件 | 行情含义 |
| --- | --- | --- |
| `pre_market` | 工作日 00:00–09:30 | 上一交易日收盘 |
| `trading` | 09:30–11:30 或 13:00–15:00 | 盘中最新（quote 走 AKShare spot） |
| `lunch` | 11:30–13:00 | 上午最新 |
| `closed` | 工作日 15:00 后 | 当日收盘；未入库则上一交易日 |
| `holiday` | 周末 | 最近交易日收盘 |

入库 `run_once` 的交易时段含 15:00–15:30 buffer，对齐个股 quotes ingest。

## 8. 入库调度

独立服务，**不要**并进 `QuotesIngestionService`（那个走 `rt_k`、6 位 `code`、写 `market_quotes`）。

配置（挨着现有 `QUOTES_INGEST_*`）：

- `INDEX_QUOTES_INGEST_ENABLED` 默认 `True`
- `INDEX_QUOTES_INGEST_INTERVAL_SECONDS` 默认 `60`

`app/main.py` 在个股 `quotes_ingestion_service` 之后注册：

1. `run_once`：`IntervalTrigger`，交易时段拉 6 只快照

单只失败记 status，不阻断其余 5 只。查询侧永远可降级外部源。

## 9. API 落点与错误码

统一前缀 `/api/indexes`，鉴权 `Depends(get_current_user)`，成功走 `ok(data)`。

| 方法 | 路径 | 处理函数 |
| --- | --- | --- |
| GET | `/api/indexes` | 目录，无行情 |
| GET | `/api/indexes/quotes` | 批量；`codes` 逗号分隔，空=6 只 |
| GET | `/api/indexes/{code}/quote` | 单只行情 |

不提供 POST。v1 无分页。

错误对齐 `app/routers/stocks.py`：抛 `HTTPException`，测试断言 `detail`（中文）。接口设计 §9 的 `{success:false}` 业务包让路给该惯例。

| HTTP | 场景 |
| --- | --- |
| 400 | 无法解析、裸 `000001` |
| 401 | 未登录 |
| 404 | 已解析但无行情 |
| 502 | 批量 6 只全失败且无缓存 |
| 504 | `wait_for` 超时 10s |

## 10. 已知坑与不改清单

| 坑 | 处理 |
| --- | --- |
| `000001` 个股 / 指数同号 | 裸码拒绝；集合主键用 `full_symbol` |
| `_normalize_ts_code` | 指数路径不调用 |
| 盘中 Tushare 日线 | 指数路径不调用 Tushare |
| Tushare amount 千元 | 不再取 Tushare 指数成交额 |
| BaoStock `get_kline` 现返回 `None` | 不改个股方法；指数也不走 BaoStock |
| 现有 kline 测试 override `app.routers.auth` | 指数测试必须 override `auth_db.get_current_user` |
| `docs/design/README.md` 曾指向不存在的接口设计文件 | 本文档落地时改为 miniprogram 路径 |

明确不改：

- `app/routers/stocks.py`、`/api/stocks/**`
- `QuotesIngestionService`、`market_quotes`、`stock_daily_quotes`
- `stock_models.ExchangeType`
- `tradingagents/dataflows/providers/china/tushare.py` 的 `_normalize_ts_code`
- BaoStock 个股 `get_kline`
- 前端与小程序
